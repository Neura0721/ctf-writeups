# ctf-writeups

渗透测试实战 Writeup —— 完整攻击链复盘

记录渗透实战项目的完整过程：从信息收集到权限提升，每一步的思路、命令与踩坑记录。

## Writeup 列表

### 1. GoldenEye —— 多阶段渗透与提权

**攻击路径：** 信息收集 → 弱口令爆破 → 横向移动 → 隐写取密 → Web 漏洞利用 → 本地提权

| 阶段 | 手段 |
|---|---|
| 端口扫描 | Masscan + Nmap 全端口扫描，定位 25 / 80 / 55006 / 55007 |
| 初始信息 | Web 源码审计 + JS 分析提取用户名，解码页面编码字符串获取凭据 |
| 凭据获取 | Hydra 爆破 POP3 服务，netcat 手工交互读取邮件实现横向移动 |
| 二次入口 | hosts 伪造域名进入 Moodle 2.2.3；图片隐写提取 Base64 拿到管理员密码 |
| 获取 Shell | Metasploit 利用 **CVE-2013-3630**（Moodle RCE） |
| 权限提升 | **CVE-2015-1328**（overlayfs 本地提权）→ root |

**关键点：** 邮件系统作为横向移动跳板；隐写术在真实渗透中的应用。

### 2. Drupal 7 —— 远程代码执行与内核提权

**攻击路径：** 主机发现 → 端口扫描 → 漏洞利用 → 字典爆破 → 内核提权

| 阶段 | 手段 |
|---|---|
| 主机发现 | Netdiscover 结合 MAC 地址定位目标 |
| 端口扫描 | Nmap 全端口扫描，发现 1898 端口运行 Drupal 7 |
| 获取 Shell | Metasploit 利用 **CVE-2018-7600**（Drupalgeddon 2） |
| 权限提升 | cewl 生成定制字典爆破 SSH；**CVE-2016-5195**（脏牛）提权至 root |

**漏洞原理分析：** Drupal Form API 未正确过滤 `#` 开头的特殊渲染数组，攻击者注入 `#post_render` 回调指向 `system` / `exec`，渲染引擎处理时直接调用该回调，导致任意 PHP 代码执行。

**提权方案对比：** 分析脏牛（CVE-2016-5195）与 overlayfs（CVE-2015-1328）的适用条件与稳定性，最终选用脏牛。

### 3. AI Web 1.0 —— 信息泄露与 SQL 注入

**攻击路径：** 目录发现 → 敏感信息泄露 → 注入点探测

| 阶段 | 手段 |
|---|---|
| 目录发现 | robots.txt 泄露 2 条隐藏路径；递归目录爆破定位 `/m3diNf0/`、`/se3reTdir777/uploads/` |
| 信息泄露 | `info.php` 泄露 Web 绝对路径与环境变量 |
| 注入探测 | Burp Suite 抓包分析参数，SQLMap 探测注入点并提取数据库信息 |

**关键点：** robots.txt 与目录爆破的组合使用；信息泄露如何为后续利用提供支撑。

## 方法论总结

```
信息收集  →  漏洞探测  →  漏洞利用  →  权限提升  →  横向移动
   ↑                                                      ↓
   └──────────────── 持续信息收集 ◄───────────────────────┘
```

**几个反复奏效的点：**

1. **信息收集永远不嫌多** —— 邮件内容、页面注释、JS 文件、robots.txt 都可能是突破口
2. **凭据复用是横向移动的核心** —— 一个系统的弱口令往往能撬开下一个系统
3. **提权前先看内核版本** —— `uname -a` 之后对照 EXP 库，比盲目尝试高效得多
